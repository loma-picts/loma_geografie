# Geografie – Interaktive Lerntools

Startseite und Sammlung interaktiver Geografie-Lerntools für die Sekundarschule.

## Live-Seite (GitHub Pages)

`https://loma-picts.github.io/loma_geografie/`

## Enthaltene Tools

- **Erdkugel: Tag und Nacht** (`./erdkugel/erdkugel-tag-nacht.html`): 3D-Globus mit Tag- und Nachtgrenze, Jahreszeiten, Erdachse und Ortssuche.

## Neues Tool hinzufügen

1. Einen neuen Unterordner im Repository anlegen, z. B. `klimadiagramm/index.html`.
2. In `tools.js` einen neuen Eintrag zu `window.GEO_TOOLS` hinzufügen und `status: "ready"` setzen.
3. Änderungen committen und auf `main` pushen – die Startseite zeigt das neue Tool automatisch an.
